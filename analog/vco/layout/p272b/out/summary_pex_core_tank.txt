# P2.7.2c Magic RC extract — vco_core_tank tn/tp [PEX-RC]

## Method
- Tool: Magic 8.3.685 + `ihp-sg13g2.magicrc`, hierarchical `extract all`,
  `ext2spice hierarchy on`, `cthresh 0` [TOOL].
- Spiral inductor `l2n0` / `l2n0_em` removed for extract: Magic treats the coil as a
  DC short (continuous metal), which merges `tn` and `tp`. Extract GDS:
  `out/pex_core/vco_core_tank_noL.gds` [PEX-RC]. Inductor pad C therefore not included.
- Intentional `cap_rfcmim` / MOSFET models are devices (not in parasitic `cap` lines).
- Units: Magic `.ext` aF / 1000 = fF.
- Series R: `extresist` not run this job [TOOL].
