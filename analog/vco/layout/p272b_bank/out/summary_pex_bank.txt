# P2.7.2c Magic RC extract — vco_bank tn/tp [PEX-RC]

## Method
- Tool: Magic 8.3.685 + `ihp-sg13g2.magicrc`, hierarchical extract on accepted
  `vco_bank.gds` [TOOL].
- Layout geometry is independent of code; “all off / all on” is a SCH device state,
  not a second GDS. One extract covers wiring parasitics for both [PEX-RC].
- Full-net substrate node C (~120–129 fF) includes MIM top-plate metal area merged
  onto `tn`/`tp`. Device `cap_rfcmim` / `cmim` models already carry plate C in SCH,
  so that area term is **not** used as “added wiring”.
- **Wiring add** = (C all partners + substrate) − substrate node C
  (= coupling to other nets, including half of C(tn−tp) attribution per side).
- Series R: `extresist` not run [TOOL].
