## Root cause `[SCH]`

**Primary: conduction-angle / diode-Vth loss not cancelled by the DC replica.**

Hold nodes sit at ≈ sfp_max − Vth ≈ 0.91 − 0.40 ≈ 0.51 V. The replica hold
has no bleed current, so its diode is off (Vgs ≈ 0) and vhr ≈ sfr (DC SF source
≈ 0.50 V). Therefore:

  vhp − vhr ≈ (CM + Amp_sf/2 − Vth) − CM = Amp_sf/2 − Vth ≈ 0.39 − 0.40 ≈ 0

  A_est = (vhp − vhr) + (vhn − vhr) ≈ Amp_sf − 2·Vth ≈ 0

which matches the measured A_est ≈ 0.03 V against Amp ≈ 1.28 V.

**Secondary:** AC attenuator C_ac=4 fF vs Cgg cuts tank→gate swing (att ≈ 0.74),
so Amp_sf is already ~0.74× the tank half-swing and the Vth eat is relatively larger.

**Not the cause:**
- Bias current too high for hold cap — there is no intentional bleed on the hold;
  I_bias is the SF tail. Hold does peak-detect; it simply peaks one Vth below SF peak.
- Per-side vs differential mix-up — the formula vhp+vhn−2·vhr is the right estimator
  *if* holds tracked peaks relative to a replica that shared the same Vth drop.
- Wrong reference / netlist error — nodes and naming are consistent; SF swings are sane.

**Implication for redesign:** use a differential max detector (shared source on tp/tn)
versus a replica of the same devices/bias at CT, so both sides run the same Vgs/conduction
physics; fold any residual constant conduction-angle loss into a fixed design-time
threshold offset (V_LOSS), no per-part trim.
