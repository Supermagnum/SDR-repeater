## 5. [HAND] PN bound from pulling / kick-back / isolation

- tt_3.65: Δf = +55.2 ppm; ΔAmp = +0.0001 V; kick f0/2 = -125.4 dBc; kick f0/3 = -107.0 dBc `[SCH]`
- ss85_4.20: Δf = -5.0 ppm; ΔAmp = -0.0001 V; kick f0/2 = -131.3 dBc; kick f0/3 = -117.9 dBc `[SCH]`

Method `[HAND]`: (1) static Δf ≤ 80 ppm is a bias/code shift, not L(f); (2) reverse isolation ≈ 68 dB from divider input to tank (divider noise to tank attenuated by that); (3) coherent kick-back at f0/2 and f0/3 is a spur, not broadband L — worst kick -107.0 dBc `[SCH]`; (4) buffer-only PSS ΔL(1 MHz) = +0.14 dB (`summary_pn_real_buf.txt`). **Bound: ΔL(1 MHz) from adding CML ≤ +0.3 dB** → total real-load Δ ≤ +0.5 dB gate (buffer 0.14 + CML 0.3). PSS with CML still required for SCH confirmation; if it fails, this bound stands.
