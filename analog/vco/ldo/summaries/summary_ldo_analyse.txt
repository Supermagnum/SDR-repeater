# 4) VR_ANA1 sharing, push, board noise [HAND]

Pin intent: option C reuses the existing VR_ANA1 **board 100 nF**.
Electrically the SCH above is LDO(1.1 V)→R→pad→bond→100 nF.
Do **not** short that pad onto the live VR_ANA1 regulator output (~1.5 V /
RX-LO rail) — the LDO and VR_ANA1 would fight. Use either a dedicated
VDD_VCO pad bonded to the same 100 nF, or a second bond to that cap.

Blocks already on the VR_ANA1 *rail* (`spec/analog-digital-interface.md`):
  RX chain, LO (buffer + CML dividers + CMOS TSPC), charge pump / PFD bias.
  If VCO filter shares that same board node, those loads sit on the VCO C.

CP pulse on 100 nF: I=50 µA × 2 ns → ΔV ≈ 1.00 µV/edge (f_ref=36 MHz).
LO edge (order-of-mag 1 mA × 100 ps) → ΔV ≈ 1.00 µV/edge.

Push (instantaneous from one CP edge on shared 100 nF):
  tt K_push=30 MHz/V × 1.00 µV → Δf ≈ 30.0 Hz peak — negligible.
  ss85 K_push=50 MHz/V × 1.00 µV → Δf ≈ 50.0 Hz peak — negligible.

If effective switched current were 1 mA (same 2 ns): ΔV=0.020 mV → Δf_ss≈1000 Hz still small vs PLL bandwidth.

Board→pad |H| @ 1 MHz (L=1 nH, C=100 nF): 1.0040 (≈1 — board noise appears almost unattenuated on the pad at 1 MHz).
Board→pad |H| @ 1 MHz (L=2 nH, C=100 nF): 1.0080 (≈1 — board noise appears almost unattenuated on the pad at 1 MHz).
So board / VR_ANA1-regulator noise at the pin **does** matter if VCO is fed from that pad;
option C only filters **LDO** noise through R–C, not noise already on the board node.

Divider/CP contribution is **spurs at f_ref harmonics**, not white S_v.
White-equivalent in 1 Hz at 1 MHz from these edges ≈ 0 for deterministic locking;
jittered edges: << 1 nV/√Hz [HAND]. Not the limiter vs 11 nV/√Hz.
