# Converting IHP Open PDK (sg13g2) for use with VACASK

First, clone the IHP SG13G2 PDK
```
git clone https://github.com/IHP-GmbH/IHP-Open-PDK
```
Now you have the latest version of the PDK in a directory named `IHP-Open-PDK`. Enter the directory and move to the development branch. 
```
cd IHP-Open-PDK
git checkout dev
```
Update submodules
```
git submodule update --init --recursive
```

If conversion fails or the converted PDK does not work, you can try again with commit e8fba183eb8f40bbbb7319eecab7d68d040da51d from the development branch by typing (immediately after clone)
```
cd IHP-Open-PDK
git checkout e8fba183eb8f40bbbb7319eecab7d68d040da51d
git submodule update --init --recursive
```

Set environmental variables
* `PDK_ROOT` to the directory where you downloaded the PDK (e.g. `/home/myname/IHP-Open-PDK`) and
* `PDK` to `ihp-sg13g2`. 

You will need the path to VACASK's Python scripts. If you don't know where these scripts are, type
```
vacask -dp
```
and look for "Python path addition". Suppose the python path addition is `/usr/local/lib/vacask/python`. Type
```
PYTHONPATH=/usr/local/lib/vacask/python python3 -m vacask.sg13g2tovc
```
Additional options can be passed to the OpenVAF-Reloaded Verilog-A compiler with `--openvaf-options`. All arguments that follow this flag are forwarded to OpenVAF. For example, to build generic models that run on any x86-64 CPU
```
PYTHONPATH=/usr/local/lib/vacask/python python3 -m vacask.sg13g2tovc --openvaf-options --target_cpu generic
```

The converter will process the Ngspice models and 
* create directory `ihp-sg13g2/libs.tech/vacask/models` with the converted models
* create directory `ihp-sg13g2/libs.ref/sg13g2_stdcell/vacask` with the converted standard cells
* create directory `ihp-sg13g2/libs.ref/sg13g2_io/vacask` with the converted I/O cells
* create a VACASK config file `ihp-sg13g2/libs.tech/vacask/.vacaskrc.toml`
  (copy this file to the directory where your toplevel netlist is located)
* patch xschem symbols with the VACASK netlisting pattern (`libs.tech/xschem/sg13g2_pr` and `libs.ref/sg13g2_stdcell/sym/xschem` directories)
* patch the Xschem configuration file `ihp-sg13g2/libs.tech/xschem/xschemrc`
* add a VACASK customization file for Xschem (`ihp-sg13g2/libs.tech/xschem/xschem-vacask`)
* compile the Verilog-A models that are provided with the PDK and place the 
  resulting .osdi files in `ihp-sg13g2/libs.tech/vacask/osdi`
* create an include file `ihp-sg13g2/libs.tech/vacask/models/sg13g2_vacask_common.lib`
  (always include this file along with all other PDK files)

Some examples and a [.vacaskrc.toml](.vacaskrc.toml) configuration file are available in this directory. Just set the `PDK_ROOT` and the `PDK` environmental variables and run examples with VACASK. The [.vacaskrc.toml](.vacaskrc.toml) file must be copied either to the user's home directory or to the directory where VACASK is started. 

![Xschem showing the dc_lv_nmos.sch example.](dc_lv_nmos.png)

# Using Xschem with the converted IHP Open PDK

First, read the section on [using Xschem with VACASK](../xschem/README.md). Next (if you still did not do it), apply the included converter to the IHP Open PDK (see the previous section). The converter patches all symbols provided by the PDK in the `ihp-sg13g2/libs.tech/xschem/sg13g2_pr` directory so that they can be used for creating VACASK netlists. 

Before you start Xschem make sure the `PDK_ROOT` and the `PDK` environmental variables are set. Set the `XSCHEM_NETLIST_TYPE` environmental variable to `spectre` and copy the Xschem configuration file [xschemrc](xschemrc) to the directory where you intend to start Xschem. This file will chain-load the IHP PDK's Xschem configuration file. The latter loads IHP PDK's Xschem extensions and symbols at startup. Now you can start Xschem. 

For VACASK simulations to work when invoked from Xschem you will have to copy the [.vacaskrc.toml](.vacaskrc.toml) file to the user's home directory. Netlists will be created and VACASK will be started in the `simulations` subdirectory of the directory where Xschem was started. 

Three simple examples are provided. The first example [dc_lv_nmos.sch](dc_lv_nmos.sch) is an analog circuit. The generated netlist contains a control block that performs an operating point analysis, a 1D operating point Sweep, and a 2D operating point sweep. The 2D sweep is plotted by the embedded Python script. By holding the Control button and left-clicking the `SimulateVACASK` launcher you can start the simulation. The operating point results can be loaded with the `Op annotate` launcher and the results of the dc2 analysis can be plotted in the embedded graph with the `Load waves` launcher. 

The second example [tran_inv.sch](tran_inv.sch) demonstrates the operationm of a simple inverter from the `sg13g2_stdcells` library. When simulating circuits that comprise components from this library make sure to define the potentials¸ of nodes `VDD` and `VSS` (i.e. connect a voltage source with the corresponding DC value to each of the two nodes). 

The third example simulates a RS latch. This example uses the analyses Xschem library for setting up the analyses. 

![Xschem showing the tran_rs.sch example.](tran_rs.png)

Currently HBT operating point backannotation does not work because VACASK uses the Verilog-A version of the VBIC model which does not expose operating point data. Once the VBIC model is converted from Ngspice to Verilog-A this feature will be added.

===== /foss/tools/vacask/share/doc/vacask/test/test_pnoise3.sim
Unmodulated PSS noise equals small-signal noise (LTI equivalence)

ground 0

load "rcnoise.va"

model resistor res
model capacitor cap
model isource isource

// Noisy resistor with white, shot, and bias-dependent flicker noise, in parallel
// with a capacitor so the gain depends on frequency. The bias is DC only (the
// sine has zero amplitude), so the circuit is time invariant and pnoise must
// give the same result as plain small-signal noise at the same physical
// frequency. $mfactor checks that the modulation function carries the same
// scaling as the noise density used by noise analysis.
r1 (1 0) resistor r=1k pw0=1e-18 pw1=3 pf=1e-9 ef=1.2 $mfactor=3
c1 (1 0) capacitor c=100n $mfactor=2
i1 (0 1) isource type="sine" sinedc=1m ampl=0 freq=1k

control
  abort always

  options rawfile="binary" strictsave=1

  save full

  // Output and input at DC harmonic, physical frequency equals offset frequency
  analysis pn0 pnoise tper=1m maxharm=8 truncharm=3 in="i1" out="1" values=[10, 100, 300, 2500]
  analysis noise0 noise in="i1" out="1" values=[10, 100, 300, 2500]

  // Output and input at the +1 harmonic, physical frequency is offset + 1000
  analysis pnp pnoise tper=1m maxharm=8 truncharm=3 in="i1" out="1" outharm=1 inharm=1 values=[10, 100, 300, 2500]
  analysis noisep noise in="i1" out="1" values=[1010, 1100, 1300, 3500]

  // Output and input at the -1 harmonic, physical frequency is |offset - 1000|
  analysis pnm pnoise tper=1m maxharm=8 truncharm=3 in="i1" out="1" outharm=-1 inharm=-1 values=[10, 100, 300, 2500]
  analysis noisem noise in="i1" out="1" values=[990, 900, 700, 1500]

  // Solve PSS with a nodeset from a solution at a different bias (2mA). The bias
  // dependent noise sources must be evaluated at the converged 1mA solution,
  // not at the nodeset, so the result must equal pn0.
  alter instance("i1") sinedc=2m
  elaborate changes
  analysis pssother pss tper=1m maxharm=8 store="pssother"
  alter instance("i1") sinedc=1m
  elaborate changes
  analysis pnn pnoise tper=1m maxharm=8 truncharm=3 in="i1" out="1" nodeset="pssother" values=[10, 100, 300, 2500]

  postprocess(PYTHON, "runme.py")
endc

embed "rcnoise.va" <<<FILE
`include "constants.vams"
`include "disciplines.vams"

module res(A,B);
    // Resistor with constant white, shot, and flicker noise

    inout A, B;
    electrical A,B;

    branch (A,B) br;

    (*desc= "Resistance", type="instance", units = "Ohm"*) parameter real r = 1 from [0:inf];
    (*desc= "White noise factor (constant)", type="instance", units = ""*)  parameter real pw0 = 0;
    (*desc= "White noise factor (current)", type="instance", units = ""*)  parameter real pw1 = 0;
    (*desc= "Flicker noise power", type="instance", units = ""*)  parameter real pf = 0;
    (*desc= "Flicker noise exponent", type="instance", units = ""*)  parameter real ef = 1.0;
    (*desc= "Current", units ="A" *) real i;

    analog begin
        I(br) <+ V(br)/r;
        i = V(br) / r;
        I(br) <+ white_noise(pw0, "white_const");
        I(br) <+ white_noise(pw1*2*`P_Q*i, "white_shot");
        I(br) <+ flicker_noise((i>=0?1:-1)*pf*pow(abs(i),2), ef, "flicker");
    end
endmodule

module cap(A,B);
    // Linear capacitor

    inout A, B;
    electrical A,B;

    (*desc= "Capacitance", type="instance", units = "F"*) parameter real c = 1p from [0:inf];

    analog begin
        I(A,B) <+ ddt(c*V(A,B));
    end
endmodule

from vacask.rawfile import rawread
from vacask.vacaskpp import *
from vacask.runtest import *
import numpy as np
import sys

tests=[]

# Quantities to compare, including the contributions of the individual noise sources
keys = ['onoise', 'gain', 'n(r1)', 'n(r1,white_const)', 'n(r1,white_shot)', 'n(r1,flicker)']

# Compare the keys of a pnoise result to a noise result, append pass/fail of each to tests
def compare(label, pnName, refName, keys, tests):
    pn = rawread(pnName+'.raw').get()
    ref = rawread(refName+'.raw').get()
    for k in keys:
        err = np.abs(pn[k].real/ref[k].real-1).max()
        status = err<1e-6
        print(label, k, "max rel err =", err, status)
        tests.append(status)

compare('dc harmonic', 'pn0', 'noise0', keys, tests)
compare('+1 harmonic', 'pnp', 'noisep', keys, tests)
compare('-1 harmonic', 'pnm', 'noisem', keys, tests)
compare('nodeset', 'pnn', 'noise0', keys, tests)

if isTest():
    sys.exit(not all(tests))

from vacask.rawfile import rawread
from vacask.runtest import *
import numpy as np
import sys

tests = []

# floor is the smallest value that counts as nonzero, it depends on the scale of the results
def compare(tests, ref, name1, name2, floor):
    a = rawread(name1).get()
    b = rawread(name2).get()
    status = True
    for n in a.names:
        if n not in b.names:
            print(name2, "is missing", n)
            status = False
            continue
        # Missing points would make the comparison of empty slices succeed
        if len(a[n])==0 or len(a[n])!=len(b[n]):
